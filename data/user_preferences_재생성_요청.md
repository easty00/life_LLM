# user_preferences 재생성 요청

## 1. 배경

**LIFE,FIT** — 라이프스타일에 맞는 서울 행정동을 추천하는 서비스를 만들고 있습니다.

사용자가 검색창에 자유롭게 입력하면(예: "산책 좋아하고 조용한 데"),
그 문장을 **7개 지표의 가중치**로 바꾸고, 그 가중치로 427개 행정동의 점수를 계산해
상위 5곳을 추천하는 구조입니다.

7개 지표: **녹지, 안전, 교통, 상권, 의료, 교육, 문화** (각 1~5점)

---

## 2. 지금 무엇이 문제인가

가상 회원 100명(C001~C100)이 있습니다. 각 회원은 두 가지를 갖고 있습니다.

- **페르소나 서술문** — 성격·직업·운동·문화·여행·음식·가족 등 9개 항목의 자연어 묘사
- **user_preferences** — 7개 지표의 가중치 (1~5점)

그런데 이 둘이 **서로 무관하게 만들어졌습니다.**
페르소나에 "매일 산책한다"고 적힌 사람의 녹지 가중치가 1점인 식입니다.

### 실제 검증 결과

"검색어와 라이프스타일이 비슷한 회원 5명"을 벡터 검색으로 찾아,
그 사람들의 가중치가 무작위 5명과 다른지 측정했습니다.
(무작위 5명 뽑기를 1,000번 반복한 분포와 비교, z점수)

| 검색어 | 기대되는 지표 | z점수 | 판정 |
|---|---|---|---|
| 산책 좋아하고 조용한 데 | 녹지 ↑ | **-1.57** | 정반대 |
| 맛집 탐방이 취미예요 | 상권 ↑ | -0.67 | 반대 방향 |
| 애들 학원 보내기 좋은 곳 | 교육 ↑ | -0.36 | 구별 안 됨 |
| 병원 가까운 게 중요해요 | 의료 ↑ | +0.35 | 구별 안 됨 |

4개 중 하나도 유의미한 신호가 없었습니다.
가중치가 페르소나와 무관하게 배정되었다는 뜻입니다.

---

## 3. 요청 사항

**회원 100명의 페르소나 서술문을 읽고, 그 사람에게 맞는 7개 가중치를 다시 매겨 주세요.**

입력 파일: `member_persona.csv` (100줄)

| 칸 | 내용 |
|---|---|
| customer_id | C001 ~ C100 |
| persona | 종합 인물 묘사 |
| professional_persona | 직업·일하는 방식 |
| sports_persona | 운동 습관 |
| arts_persona | 문화·예술 취향 |
| travel_persona | 여행 성향 |
| culinary_persona | 식생활 |
| family_persona | 가족 관계 |
| cultural_background | 자란 배경 |
| career_goals_and_ambitions | 커리어 목표 |

---

## 4. 출력 형식

CSV 파일 하나. 칸 이름과 순서를 아래 그대로 지켜 주세요.

```
customer_id,녹지,안전,교통,상권,의료,교육,문화
C001,4,5,3,2,5,1,2
C002,2,3,5,5,2,3,4
...
```

- 값은 **1~5 사이 정수만** (소수점 없음)
- 100줄 전부 (C001 ~ C100, 빠짐없이)
- 헤더 포함, UTF-8

## 5. 매길 때 지켜 주실 것

### 지표 정의

| 지표 | 무엇을 뜻하는가 |
|---|---|
| 녹지 | 공원, 산책로, 자연환경 접근성 |
| 안전 | 치안, CCTV, 경찰서 |
| 교통 | 지하철·버스 접근성 |
| 상권 | 마트, 식당, 카페, 시장 |
| 의료 | 병원, 의원, 약국 |
| 교육 | 학교, 학원 |
| 문화 | 도서관, 공연장, 전시관 |

### 원칙

1. **페르소나에 근거를 두세요.**
   "주말마다 북한산 둘레길을 걷는다" → 녹지 높게
   "일주일에 대여섯 번 외식한다" → 상권 높게

2. **개인차가 드러나야 합니다.**
   전원이 3점 근처로 몰리면 안 됩니다. 이번 작업의 목적 자체가
   "사람마다 다른 취향"을 만들어 내는 것입니다.
   지표별로 1점부터 5점까지 고르게 분포하는 것이 이상적입니다.

3. **간접 신호도 읽어 주세요.**
   - 어린 자녀 언급 → 교육·안전 높게
   - 70대·지병 언급 → 의료 높게
   - 재택근무·자차 이용 → 교통 낮게
   - 집에서 쉬는 것을 즐김 → 상권·문화 낮게

4. **모든 지표를 높게 주지 마세요.**
   한 사람이 7개 전부 4~5점이면 정보가 없는 것과 같습니다.
   그 사람이 **무엇을 포기할 수 있는지**도 함께 판단해 주세요.

5. **거주지는 무시하세요.**
   페르소나에 광주·용인 등 서울 밖 지명이 나올 수 있습니다.
   이 회원들은 서울 거주자로 설정된 가상 인물이므로,
   지명이 아니라 **생활 방식만** 보고 판단해 주세요.

---

## 6. 검증 방법 (작업 후)

만들어 주신 결과가 제대로 되었는지는 이렇게 확인할 예정입니다.

- 지표별 표준편차가 1.0 이상인가 (개인차가 있는가)
- "산책을 즐긴다"고 적힌 회원들의 녹지 평균이 전체 평균보다 높은가
- 한 사람의 7개 값이 전부 같은 방향으로 쏠려 있지 않은가
